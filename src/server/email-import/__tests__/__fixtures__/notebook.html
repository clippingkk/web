经略幽燕：宋辽战争军事灾难的战略分析 (曾瑞龙)
曾瑞龙
目錄
Highlight(yellow) - Location 197
在日常用語中，和平常常被賦予更積極的意義。所謂「維護世界和平」的口號中所講的「和平」，很難想像其內涵包括了互相確保摧毀在內。
Highlight(yellow) - Location 515
以往史家喜歡強調在「強榦弱枝」政策下，將領的作戰自由受了限制，不能隨機應變。然而這只是問題的一個方面，更大的問題不在於武將應否擁有作戰自由，而在於如何能令他們執行原來的作戰計劃。宋軍由於機動力量不及遼軍，在戰術上頗為仰賴幾支不同部隊在關鍵地點進行夾擊，但是隨着軍事行動涉及較多的單位，組織風險亦為之提高。戰場上的事態千變萬化，指揮官可能在不同的事態下各自作了不同的判斷，這些判斷對他們各自指揮的部隊而言可能是比較有利的，但卻很容易導致整體作戰計劃中途擱淺。
Highlight(yellow) - Location 551
北宋經略幽燕是一系列典型的軍事災難。宋軍受到五代相沿襲用的軍事信念所影響，偏好野戰，崇尚奇襲。當面對相對上強大，亦同樣擅長野戰的遼軍，宋人未能透過新的思維去改變戰略的取向，不但令戰鬥風險偏高，也增加了發生軍事災難的可能性。簡單地說，當對手不再是割據政權，而是邊疆民族建立的國家的時候，北宋在大戰略上雖然有所檢討，提出了內政主導的思路，但並沒有隨之而改變其軍事戰略。
Highlight(yellow) - Location 557
雖然我們無法否定經驗的價值，但無論如何，擺脫過時的軍事信念，和敏銳地總結新近的經驗，對於避免軍事災難而言，非常重要。
Highlight(yellow) - Location 1783
這時晉出帝發動一個反擊，命令諸將尾隨契丹主力，並攻陷了滿城和遂城。耶律德光本已從古北口出塞，聽到這個消息，立即擁八萬餘騎掉頭南進。 [2-63]晉軍結陣退至陽城白團衛村，被契丹軍追上，便四面布下鹿角，據寨堅守。契丹軍切斷了晉軍糧道，晉軍面臨斷水斷糧。這時耶律德光下了殲滅晉軍，然後進軍開封的決心，下令鐵騎下馬，拔除鹿角，又順風縱火，以助兵勢。 [2-64]同時晉軍寨內也召開了緊急的軍事會議。都招討使杜重威（卒於 948年）主張等風勢稍緩，再決定怎樣行動。都監李守貞（卒於 949年）卻認為在風沙中出擊反而是有利的事情。符彥卿亦宣稱寧願決一死戰，於是擁精騎出西門決戰。當時風勢更強，天色昏暗，符彥卿率領一萬騎兵橫衝契丹大陣。李守貞亦命步兵齊出，拔除鹿角，向前追擊二十餘里。遼軍鐵騎下馬後一時間不能再上，大敗而逃， [2-65]散兵退至陽城東南，稍能恢復陣列，晉軍騎兵又追到。耶律德光棄車而遁，乘坐一隻駱駝逃離戰場。
Highlight(yellow) - Location 1824
無可否認，耶律德光對於中國文化具有相當認識，可是他沒有全盤漢化的意圖。如果他正式當起中原的皇帝，他會面臨治理龐大農業人口的問題，和置身於複雜的中央和藩鎮間的利益衝突。可是他似乎也了解到中原巨大的經濟和軍事潛力，使他不放心將幅員廣大的領土交給一些同樣具有政治野心的降將來治理，結果還是要親自嘗試統治中原的各種困難，也招徠挫折。
Highlight(yellow) - Location 1950
傳統史家多將宋人形容為備受侵略的一方，這種多少有一種漢族為中心的偏見的認知，可能受到民族主義的思維模式輾轉加強，而很少受到質疑。然而不少史料記載，遼人也難以防止來自中原軍隊的抄掠。宋初高陽關縣治的遷徙，反映了遼人在以往後周軍隊侵擾之下如何退避三舍。
Highlight(yellow) - Location 2703
後世看到的是宋太宗成功地消滅北漢，為了收回幽燕割讓地而發動戰爭，從民族立場評價，可能還覺得是正義之師；然而如果將事實理解為不管宋人是否能取得河東，只要遼人繼續支持北漢並派出援軍，戰爭就立即爆發的話，負這樣的戰爭風險是否值得，可能就需要重估。由於史料所限，宋太宗心中的想法已不可能確知。根據多年後所追述，當時他年少氣銳，在進軍幽州途中，就那樣騎着馬下水渡過桑乾河，而不取道橋樑。 [3-98]如果宋太宗晚年的記憶沒有隨着戰局的逆轉而扭曲，那麼一時意氣，可能是令宋太宗急於經略幽燕的心理因素。
Highlight(yellow) - Location 3808
對於戰略文化的研究者來說，高梁河戰役也許是一個很好的例子，說明軍事信念的偏狹性。軍事信念往往由軍事經驗累積而成，而過去的成敗就成為未來的指路南針。久而久之，軍事信念成為戰略的基本假設。可是在戰略決策中不可忽略的是，決策者必須清晰地了解到軍事信念是從歷史經驗和文化背景層累地形成，一旦戰略議題進入了一個嶄新的歷史框架，原來構成那種軍事信念的主客觀環境改變了，戰略的基本假設就不得不重新檢討，否則就有可能遇上軍事災難。
Highlight(yellow) - Location 3952
總體來說，太宗沒有在第一階段作戰，即消滅北漢之後發下軍賞；然後馬上發動第二階段作戰，進軍幽州，是犧牲了將士的利益，置內部的隱憂於不顧而去乘敵人之隙。這樣，他雖然贏得先發制人的戰略優勢，但代價實在高昂︰他若不能迅速決勝，軍隊中士氣不振的弱點就將表露無遺。
Highlight(yellow) - Location 3999
太宗親自指揮前線，此點頗受劣評。 [5-74]甚至他本人晚年的時候，對此亦不以為然。 993年（淳化四年）十一月，即太宗去世前三年左右，曾與呂蒙正談話，自言︰「朕往歲既克并、汾，觀兵薊北，方年少氣銳，至桑乾河，絕流而過，不由橋梁。往則奮銳居先，還乃勒兵殿後，靜而思之，亦可為戒。」 [5-75]當時他親率殿前將士，位於全軍最前列，當先抗擊遼軍；而充當預備隊的曹翰、米信部，則遠在幽州城東南方。
Highlight(yellow) - Location 4096
此役對宋軍的主要打擊，不在兵員，而在統御能力。太宗以後只能徒然自誇「往則奮銳居先，還乃勒騎殿後」， [5-120]事實上再沒有親上前線。然而他又不肯把作戰全權賦予將領，而企圖以預定的戰略、戰術來間接指揮戰役，甚至連佈陣的方法都要事先預定。大將的權威不振，執行作戰計劃的能力也連帶受了影響。某些將領看出喪失靈活性的危害，堅持「閫外之事，將帥得專」，一再違抗節制。太宗愈想統籌全局，就總是適得其反。這是高梁河戰役後宋軍的指揮系統產生的問題，不久之後發生的滿城會戰，宋軍雖然得勝，但內部的危機已表露無遺。
Highlight(yellow) - Location 4109
任何軍事信念都在特定時空環境下存在一個形成過程，可是當這種信念形成之後，它就以一個戰略文化的形態被保存着，對未來的戰略發生影響。固然，成功的經驗容易塑造良好的傳統，但是決策者也要了解，這種軍事信念是在一些特定環境中形成的，對它們的偏狹性一定要保持警惕，否則就會重蹈宋軍「乘此破竹之勢，取之甚易」的覆轍。
Highlight(yellow) - Location 4356
即使在平時的狀況下，縱深防禦也有令人憂慮的一面。它假設了國家隨時會遭受入侵，對於社會安定和經濟發展而言，並非正面因素。過於迫切的戰備，也會影響投資者的信心。因此，先進國家對縱深防禦常常持一種保留的態度。況且，過於向民眾宣傳敵軍入侵的可能性，會激生排外情緒，所以也可能會挑釁潛在的敵人。
Highlight(yellow) - Location 4797
宋太宗應該慶幸的是，他有一群具質素的將官，敢於違反他的陣圖，靈活地變陣出擊。這些優秀的軍官對於宋太宗在戰役、戰術兩個層次的干預能正確的分析，遵從戰役指導，打出部署，但對有問題的戰術則拒絕遵從。宋太宗的運氣也在於敵軍的主帥優悠寡斷，加速了遼軍的失敗。可是宋軍此役首次出現了指揮權模糊不清的狀況，對於將來發生的協調困難，未嘗不是一個警號。在瓦橋關之戰中，宋軍表現英勇，可是指揮權仍然有欠清晰，結果遭到敗北。
Highlight(yellow) - Location 5097
可是在動人事跡的背後，人民卻遭受駭人聽聞的虐殺。 [7-18]別的不說，單從人吃人的慘況，已能窺見戰亂的禍害。秦宗權（卒於 889年）的軍隊中公然設立「磨樁寨」，有計劃、有秩序地將人屠宰，充當軍糧。 [7-19]歷時逾年的鳳翔之圍（ 901），令城中人燒屎煮屍而食，人肉一百文錢一斤，狗肉五百文錢一斤，可見人肉之賤。一名父親吃掉自己的兒子，還竟然對要來爭肉吃的人說：「此吾子也，汝安得而食之！」 [7-20]李存孝向梁軍叫陣，大呼：「待爾肉以食軍，可令肥者出鬥！」據史書記載，當時應聲出鬥，並遭生擒的敵將鄧季筠（卒於 912年）幸得李克用賞識，沒有被吃掉， [7-21]可是這番話在後世稱為「十三太保」的李存孝口中說出，卻鮮明地突顯出一個活地獄——勝利者成為眾人愛戴的英雄，戰敗者則和無辜平民一樣變成犧牲品。
Highlight(yellow) - Location 5456
尤其是李德・哈特的學說，可能會為宋太宗提供一點辯謢的餘地。他總結了二十五個世紀以來西方歷史上的決定性戰役，指出幾乎所有的例證都顯示，決定性勝利並非單純由軍力衝突造成，而是某一方先讓對方喪失協調和平衡所致。要令對手失去平衡，則必須循間接路線，而非直接強攻所能做到。隱藏主要意圖，攻其無備，出其不意，是所謂間接路線的主要精神，也符合中國人「先勝而後戰」的兵法原則。
Highlight(yellow) - Location 5473
問題的徵結在於，宋太宗的迂迴戰略沒有威脅對方的補給和退卻線，也好像沒有殲滅遼軍主力的可能。一般軍事上的迂迴行動，目的是切斷對方的退路和補給，即使不能加以全殲，至少可以令對方畏懼而向後收縮，讓出土地。
Highlight(yellow) - Location 6095
正當楊業和遼軍交鋒的時候，潘美和王侁卻率部離開了陳家谷口。首先是王侁「使人登托邏臺望之，以為敵敗走。侁欲爭其功，即領兵離谷口，美不能制， ⋯ ⋯俄聞業敗，即麾兵卻走」。 [8-49]黃昏時，楊業退回陳家谷口，望見無人，於是大哭，反身力戰，結果在狼牙村中箭被擒，三日不食而死。 [8-50]他的部下據說全部戰死，無人生還。 [8-51]
Highlight(yellow) - Location 6749
檢討一下宋軍在幾次重要戰役的表現，會發覺一個很重要的教訓，就是宋軍常常因襲以往的戰略——在高梁河戰役中因襲五代的兼行速進，在君子館戰役中遲遲未能轉入守勢，都是這樣的例子。這個教訓如果具有普遍性的話，那麼很可怕的是，它揭穿了人們自以為理性的外衣，看到了其下面依循、墨守的陰影。按理性的立場說，每一場戰役的戰略如何制訂，應以當時的勢力對比為依歸，所以不同時勢，應有不同的戰略。然而宋軍幾次失敗的事實似乎指出，指揮官喜歡追隨以往成功的軍事信念，而不能因應時勢作出適當的部署調整，為失敗埋下伏筆。
Highlight(yellow) - Location 6757
不少論者都看到契丹有限的經濟不足以支持長期的軍事對抗，並認為從長遠的角度分析，持續對立令宋人得以發揮文化上的感染力和物質上的優越性。這種分析雖然含有大漢族中心主義的偏見，但不失為一個以內政為主導協調多層次的戰略對策。可是持續對立與弭兵息戰的主張也有抵觸，更不能滿足宋太宗一統中原的要求，因此這些主張只能停留在理念層次，而得不到實際施展的機會。結果長線的，把注碼押在社會經濟潛力上的戰略間接路線，被一個短線、而較倚重欺騙的戰役間接路線取代，就是宋太宗聲東擊西的計謀。這個計謀未始沒有成功的機會，但隨着曹彬糧盡退師，又再裹糧再趨涿州，整個作戰行動已失去原有的間接性，而變成硬闖的格局。因此在岐溝關的一敗，繼而再敗於君子館，宋軍的戰略主動權便為之易手了。
Highlight(yellow) - Location 6896
他們似乎忽略了危機意識可能令敵人暫時排難解紛，一致對外，正如趙普所言「若彼能同意，縱幼主以難輕，不順群情，無災星而亦敗。」 [9-16]他們也忽略了軍事手段需要長期處於臨戰狀態，才能發揮出預期效益，倉卒用兵，很可能會招徠重大的失敗。
